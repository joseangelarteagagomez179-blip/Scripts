## ✨ CARACTERÍSTICAS DEL SCRIPT
Este script está diseñado **específicamente para este juego**, adaptado a todas sus mecánicas y nombres reales, **100% en español**:

### ⚡ Sección Principal
✅ **Auto Patear Bloque:** Patea automáticamente sin parar, configurable
✅ **Patada Perfecta:** Fuerza exacta calculada para obtener la mejor recompensa y más *Brainrots*
✅ **Auto Recolectar:** Recoge monedas, dinero y todos los objetos que caen del bloque
✅ **Auto Colocar Brainrots:** Pone automáticamente los objetos en tu parcela para generar dinero pasivo 💰

### 📈 Mejoras y Progreso
✅ **Auto Comprar Mejoras:** Compra todo lo disponible en la tienda:

   - Fuerza de Piernas
   - Suerte
   - Velocidad
   - Salto
✅ **Auto Renacer:** Renace automáticamente en cuanto cumples los requisitos para multiplicar tus ganancias

### 🛡️ Seguridad y Utilidades
✅ **Sobrevivir al Tsunami:** Te eleva automáticamente y recupera vida para que no mueras cuando sube el agua 🌊
✅ **Anti AFK:** Evita que el juego te expulse por inactividad
